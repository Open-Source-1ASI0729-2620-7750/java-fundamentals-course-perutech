# java-fundamentals-course-perutech


Repositorio oficial del curso de programación en Java orientada a estudiantes de secundaria (12-17 años). Desarrollado como parte del curso de Desarrollo de Aplicaciones Open Source de la UPC.


## Estructura del Repositorio
* `/starter-files`: Contiene el código inicial para que los estudiantes comiencen las prácticas en línea sin instalar nada.
* `/completed-examples`: Contiene las soluciones completas de los ejercicios desarrollados en los videos.
* `/scripts`: Guiones y recursos de apoyo para la grabación de las lecciones.
