# Fundamentos de Java para principiantes - PeruTech

Curso introductorio de Java para estudiantes de secundaria de **12 a 17 años**, sin experiencia previa. Forma parte del Trabajo Complementario del curso 1ASI0729 Desarrollo de Aplicaciones Open Source de la UPC, ciclo 202620, NRC 7750.

Los seis videos de las cinco lecciones suman **52:41 según metadatos de YouTube**. Reserva aproximadamente una hora para verlos con pausas y tiempo adicional para los retos. La revisión audiovisual y la visibilidad No listado están pendientes de validación por el equipo.

## Empieza aquí

Solo necesitas un navegador y conexión a Internet. Las prácticas usan las modalidades gratuitas de OnlineGDB, JDoodle y OneCompiler; no necesitas instalar Java ni un editor. Sigue el orden del curso y consulta el [plan detallado en Markdown](./course-plan.md).

## Ejecutar un ejemplo en el navegador

1. Abre un archivo inicial o completo y copia **todo su contenido**.
2. En el editor elegido, selecciona **Java**, reemplaza el contenido de `Main.java` y pulsa **Run**. Copia un solo ejemplo cada vez.
3. En 3.1 proporciona un nombre y una edad entera en líneas separadas, por ejemplo `Ana` y `15`, mediante la entrada estándar del editor.
4. Compara con las [salidas verificadas](./verification/java-results.json). Los archivos iniciales con `TODO` son ejercicios y algunos no muestran nada hasta completarlos.

Aunque los archivos históricos tienen nombres como `leccion1.java`, su clase pública es `Main`; se copian como `Main.java`. No combines todos los ejemplos en un proyecto: cada uno funciona por separado, sin paquetes ni dependencias.

Para la lección 4 utiliza las rutas `lesson-04/Main.java`, basadas en `Estudiante`. Los archivos `leccion4.java` y su guion de libros se conservan como material alternativo del equipo.

## Estructura del repositorio

* `starter-files/`: código inicial de las prácticas.
* `completed-examples/`: ejemplos completos e independientes.
* `scripts/`: guiones de las lecciones; se conservan las aportaciones originales.
* `course-plan.md`: objetivos, secuencia, videos, ejercicios y datos académicos.
* `deliverables/`: PDF del plan y ZIP de artefactos del curso. Los reportes de participación se conservan únicamente en local.
* `verification/`: evidencias de ejecución, revisión de enlaces y pendientes de entrega.
* `tools/`: herramientas opcionales para verificar Java y reproducir los entregables; no las necesita el alumnado.
